# bagliapps.github.io

Developer home page → https://bagliapps.github.io. Each app lives in its own repo under a sub-path (e.g. `BagliApps/walletude` → https://bagliapps.github.io/walletude/).

`apps.json` + `apps/<name>.png`: "Other apps" list the apps fetch at launch and cache. `ios` = App Store id, `android` = Play package (add only once live on Play; an app without it is hidden on that platform). `tagline` per UI language, `en` is the fallback.
